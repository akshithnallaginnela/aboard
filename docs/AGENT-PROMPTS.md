# ConnectAbroad: execution prompts for a fresh build

Current user decision: build everything from scratch with INR 0 additional spend.
Earlier prompts that required an existing repository or stopped without source are superseded.
No application implementation has been performed by writing this package.

## 1. Complete frontend from scratch: start here

Use [CLAUDE-FRONTEND-PROMPT.md](CLAUDE-FRONTEND-PROMPT.md) as the full copy-ready task.
Open the current workspace; create `frontend/` without overwriting this package.
The selected stack is React/Vite/TypeScript, React Router Framework Mode with
`ssr: false` and approved public prerendering, Tailwind and customized shadcn/Radix.
Finish all scoped routes, explicit demo interactions and available verification.
The absent backend is expected; record its typed API contract without claiming real integration.

## 3. Parallel handoff and independent review

```text

required output per agent. Establish shared tokens/components first. Use
disjoint file ownership or isolated worktrees/test databases; one schema owner.

behavior, privacy, state, accessibility or test defects with path and minimal fix.
Distinguish observations from unavailable checks. Lead integrates, fixes findings
and verifies before marking the requested scope complete. Use sequential roles
if native subagents are unavailable; no agent-service subscription is required.
```
