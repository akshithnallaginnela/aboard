# ConnectAbroad growth

Paths below are relative to the project root. Read `docs/BUSINESS-AND-GROWTH.md`; metric definitions in `IMPLEMENTATION-PLAN.md` section 8 are canonical. This is a fresh application with ₹0 additional spend. Track labor opportunity cost separately from actual cash; no required hosting, domain, subscription, paid API, advertising, trial or model purchase. Check actual cohort evidence before recommending expansion.

## Run one learning loop

1. Name the reachable cohort, buyer/user, current pain and existing workaround. If access is unknown, propose a bounded interview/recruitment test rather than claiming a validated market.
2. Check resident/helper availability, topics and capacity before increasing demand. Respect opt-outs and any request cap. Keep the core beta free while proving useful connections.
3. Define one experiment: hypothesis, audience, offer, channel, cost including labor, owner, deadline, observable success/failure and next decision.
4. Use canonical registration/activation/reply/mature-cohort definitions. Track useful outcomes separately from activity. Do not change windows or denominators to make a target look achieved.
5. Report actual observations against assumptions, including small-sample uncertainty and unanswered requests. Repeat, narrow or stop based on that evidence.

## Revenue order and boundaries

First test a priced expression of interest for one fixed-scope organizer/community service; it is not payment or revenue. A real paid pilot needs separate execution authorization and a lawful collection/receipt/refund method compatible with the zero-spend constraint. No billing processor setup, subscriptions or call marketplace is required now.

Show contribution after delivery, helper compensation, support/moderation, acquisition, refunds/payment charges and fixed costs, with clear tax/currency/price assumptions and sensitivity to labor. No passive-income or market-leadership promises. Automation should remove observed repetitive work; it does not remove service ownership.

Read Reddit as anecdotal interview input and official competitor pages as product descriptions, not independent quality evidence. Disclose affiliations/conflicts; never imply identity verification from a completed profile.

Drafting and analysis do not authorize outreach, scraping, publishing, spending, partner promises or billing. Where actual execution is requested, use the specific authorized audience and action; do not turn a planning task into a campaign. Return one measurable experiment and the decision it will resolve.
